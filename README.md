# Mohammad Asif · DevOps portfolio

A static portfolio and technical blog built with HTML and CSS.

- `index.html` contains the profile, experience, featured project, skills, and links to the articles.
- `style.css` contains the shared design and mobile layouts.
- Each article is a separate HTML file. To add an article, copy an existing article, update its content and metadata, then link it from the Writing section.

For free GitHub Pages hosting, create a public repository named `AsifMohammad0311.github.io`, add these files to `main`, and select **Settings → Pages → Deploy from a branch → main → /(root)**. GitHub Pages will publish updates from that branch.
